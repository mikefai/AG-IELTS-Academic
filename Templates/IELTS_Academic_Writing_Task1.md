# 📊 IELTS Academic Writing Task 1: [Visual Data Description Title]

## 📌 Prompt & Stimulus Description
> **The chart/graph/table below shows [description of data/trends across categories/time].**  
> *Summarise the information by selecting and reporting the main features, and make comparisons where relevant.*  
> *Write at least 150 words.*

- **Visual Data Type**: [Line Graph / Bar Chart / Pie Chart / Table / Process Diagram / Map]
- **Time Constraints**: 20 Minutes
- **Key Data Points Summary**:
  - Highest / Dominant Category: `[Data point]`
  - Lowest / Minor Category: `[Data point]`
  - Most Significant Trend / Shift: `[Data point]`

---

## 🏗️ Structural Strategy & Paragraph Outline

1. **Paragraph 1: Introduction & Paraphrase** (1 Sentence)
   - Rephrase the prompt using advanced synonyms, prepositional phrases, and alternate syntax.
2. **Paragraph 2: The Essential Overview** (2 Sentences)
   - State the two most prominent macro-trends / general observations without citing individual data numbers.
3. **Paragraph 3: Detailed Body Paragraph 1** (3–4 Sentences)
   - Group related categories, state starting figures, and compare key trajectories with precise numbers.
4. **Paragraph 4: Detailed Body Paragraph 2** (3–4 Sentences)
   - Contrast remaining categories/time periods, highlighting anomalies or points of intersection.

## 🔍 Examiner Rubric Commentary (Band 9 Breakdown)

| Assessment Criterion | Examiner Analysis & Evidence from Model |
| :--- | :--- |
| **Task Achievement (TA)** | Covers all key features, highlights major trends accurately, overview is clear and prominent, and data is supported with precise figures without speculative outside explanations. |
| **Coherence & Cohesion (CC)** | Information is logically sequenced. Cohesive devices (*in stark contrast, whereas, following a similar upward trajectory*) are used naturally without sounding mechanical. |
| **Lexical Resource (LR)** | Features sophisticated lexical variety for trends (*plummeted, reached a plateau, experienced exponential growth, marginal fluctuations*). Spelling is error-free. |
| **Grammatical Range & Accuracy (GRA)** | Employs diverse complex structures (participial clauses, passive voice, compound-complex sentences) with total accuracy. |

## 💡 High-Yield Formulaic Expressions
- *Intro*: *"The provided [bar chart / line graph] delineates..."*
- *Overview*: *"Overall, what stands out from the data is that while [Category A] underwent a marked surge, [Category B] exhibited..."*
- *Comparisons*: *"Witnessing a twofold increase...", "...accounting for a negligible proportion of..."*

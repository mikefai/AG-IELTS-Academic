## 🎯 Target CEFR Levels & Scope

| Level | Description | Key Focus Areas |
| :--- | :--- | :--- |
| **A1 - Beginner** | Basic survival English | Simple present, basic vocabulary, daily routines, simple greetings |
| **A2 - Elementary** | Routine exchanges | Past simple, future (going to), describing places/people, shopping |
| **B1 - Intermediate** | Independent speaker | Present perfect, conditionals (0, 1, 2), modal verbs, expressing opinions |
| **B2 - Upper Intermediate**| Fluent communicator | Passive voice, mixed conditionals, relative clauses, nuanced discourse |
| **C1 - Advanced** | Complex & professional | Inversion, cleft sentences, advanced collocations, idiomatic mastery |
| **C2 - Mastery** | Near-native proficiency| Stylistic nuances, academic discourse, metaphorical language |

## 📋 Content Creation Standard

When generating ESL content:
1. **Specify CEFR Level**: Always declare the target CEFR level in the frontmatter.
2. **Pedagogical Structure**: Follow a clear methodology (e.g., **PPP**: Presentation, Practice, Production or **TBL**: Task-Based Learning).
3. **Include Answer Keys**: Provide full answer keys with explanations for non-obvious items.
4. **Scaffolding**: Provide vocabulary glossaries or sentence stems for lower levels (A1–B1).
